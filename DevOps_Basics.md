4\. `**DevOps\_Basics** 

\- \*\*Devops:\*\* Development + Operations aur Maintain. Product ko banane se lekar live karne tak ka process.

\- \*\*Tools:\*\* Git, Jenkins, Docker, AWS

\- \*\*Jenkins:\*\* Automation tool jo software ke Build, Test aur Deploy jaise kaam automatically karne me help karta hai.

\- \*\*Jenkins Pipeline:\*\* Automated process jisme steps sequence me hote hai (CI/CD automate karta hai).

\- \*\*CI / CD:\*\* CI = Continuous Integration, CD = Continuous Deployment.

\- \*\*AWS:\*\* Amazon Web Services - Cloud platform jo internet ke through servers, storage, database aur IT services deta hai.
