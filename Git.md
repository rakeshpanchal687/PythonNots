 Git & GitHub Notes

 Git & GitHub Definition

- **Git:** Git ek Version Control System Hai yo Code files ke changes ka record rakhta Hai aur Purane Version Per wapas Jaana main Help Karta Hai.

- Git Local Computer main Code manage Karta Hai.

- **Github:** Github Global /online Internet par Repository Store/share Karta Hai.

 Devops (github) Steps

1. Sabse pehle Github Per New Repository Banai.

2. us Repository Me Jakar Code Se URL Copy Kiya.

3. Desktop ek New folder banaya, folder Ko open Kar ke Address bar Mai CMD Type kiya:

 `git init`

 `git clone <Repo_URL>`

4. Desktop per jo folder Hai Uske Ander wale folder Ko open kar ke "Project" Ko Paste Karna Hai.

5. Address bar Par CMD open karein:

 `git add .`

 `git commit -m "done"`

 `git push`

 Branches & Pull

- **GitHub to Local:** `git pull`

- Ek Project Par Ek Se Jayda team Kaam Kar Rahi Hai to Alag alag Branches Banana padti Hai.

- Branch banana: `git branch <branch-name>`

- Branch push karna: `git push origin <branch-name>`
